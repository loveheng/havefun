# 缺失补全方案

## 结论（给 PM）

- **本方案性质**：按行业惯例对[数据闭环推演](数据闭环推演.md)与[需求覆盖度清单](需求覆盖度清单.md)中的缺口给出**建议默认规则**——先按行业做法把缺口补上，再由你定；全部数值为行业基准值，确认后可调，结构若要改动请在批注时一并说明。
- **三个结构性决策需你确认**：① 资金链路走「担保交易」还是「不碰钱」；② 碎银↔人民币换算 1两=1元 是否接受；③ 孤儿功能（餐厅点餐/扫一扫/商户客服/优惠券）归二期（2026-10-13 确认）。其余默认值见文末『PM 确认清单』，也要你逐条批注后才进开发——确认前它们只是建议，不构成需求。
- **合规底线已内嵌**：盲盒概率公示、账号注销、先发后审+机审、提现实名——这些不是可选项，是上架前提。

## 补全思路

1. **惯例优先**：每个缺口先给「行业怎么做」（积分体系参考京东京豆/运营商积分，UGC 审核参考抖音/小红书，跑腿参考美团跑腿/UU，二手参考闲鱼）。
2. **数值可调、结构锁定**：奖励数值、比例均为基准值（标 📊），运营可后台调整；但「有上限、有频控、有流水」的结构是硬的。
3. **首版最小闭环**：孤儿功能建议首版不做、二期按数据决定是否补（去留需 PM 定）；宁缺毋滥，不让未定义的功能上首位。
4. **合规不谈判**：凡涉资金、概率公示、隐私、注销的条目，按监管要求执行，不提供「不做」选项。
5. 本文所有 ⚠ 与上篇[数据闭环推演](数据闭环推演.md)的 ⚠ 一一对应，PM 批注后以「已确认」版本替换本篇对应行。

### 有效期与清零（待定 #4 语义歧义，需 PM 确认解读）

- **流量**：未兑换流量每月出账期（1-3日）后清零重计（§4 原规则，不动）。
- **碎银**：原文「碎银有效订单60天」语义歧义（评估 P2 #22），解读为「自入账日起 60 天有效」需 PM 确认。行业参考：滚动到期，先入先出扣减，到期前 7 天在「碎银明细」与消息中心提醒。
- **「本月到期碎银」（§15.2）**：若上条确认，= 未来 30 天内到期的碎银之和（按入账批次 FIFO 推导），该待定项自动闭合。

- 抽奖页**公示全部奖品及中奖概率**——监管要求，非可选项；公示精度需 PM 定。行业参考：精确到 0.1%。

- 概率与保底逻辑后台可配但变更留审计日志；用户端展示「本抽池概率快照」。

### 风控基线（结构建议，阈值需 PM 定）

- 发行-消耗监控报表（见『后台管理补全』）周报给运营：周发行量、周消耗量、留存量、渠道占比。

## 资金链路方案（闭合推演域三，结构性决策 ①）

### 行业惯例参考

跑腿/二手平台的资金惯例只有两条路：**担保交易**（美团跑腿/UU：报酬先付到平台托管，完成后放款）或**不碰钱**（早期闲鱼：私下转账，平台只留证据）。涉资金归集必须有支付牌照或走持牌通道（微信支付「服务商分账/合单支付」、收付通类产品），否则构成二清。

### 方案 A：担保交易（走持牌通道）

| 环节 | 方案 A 规则（参数需 PM 定） |
| --- | --- |
| 跑腿报酬 | 发布者支付 → 资金进微信/支付宝分账托管（平台不经手资金池）→ 确认完成 → T+1 分账给接单者 |
| 过期退款 | 超时无人接单 → 原路退回（到账时效需 PM 定，行业参考 T+1） |
| 平台抽成 | 原始需求未定义，需 PM 定。行业参考：首版 0%，后续走分账比例配置 |
| 充值（校园卡/网） | 代收与否需 PM 定。行业参考：不代收——APP 内选档下单，收单方为运营商/校方商户号（跳转或合单），APP 只回执，规避代收对账与开票 |
| 自营商城 | 平台商户号收款；退货退款规则需 PM 定。行业参考：7 天无理由退货、原路退款 |
| 提现 | 提现门槛/手续费/到账时效需 PM 定。行业参考：仅跑腿报酬余额可提，满 10元、免手续费（首版）、T+1 到账，后台人工审核大额 |

### 方案 B：不碰钱（合规负担最低）

- 平台不做任何代收：跑腿发布页引导**直接转账给接单者**（聊天页出示收款码），平台仅留存订单与聊天记录作纠纷证据；自营商城与充值跳转三方。
- 代价：纠纷没有仲裁依据（钱没过平台只能调解）、活动差价补款体验差、提现/收入余额模块整体下线。
- **适用场景（供 PM 参考）**：若支付资质短期办不下来且想先上线验证需求。

### 二手交易（对应推演「二手未纳入订单体系」）

原始需求未定义二手资金是否过平台，需 PM 定。行业参考（闲鱼惯例）：首版不做平台交易——发布→聊天协商→线下面交/自行转账，平台提供举报与信用展示；二期视数据决定是否上担保交易。若确认，则订单页「商品」Tab 仅指自营商城订单，二手不出订单（与推演 ⚠ 推测一致）。
