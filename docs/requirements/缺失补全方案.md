# 缺失补全方案

## 结论（给 PM）

- **本方案性质**：按行业惯例对[数据闭环推演](数据闭环推演.md)与[需求覆盖度清单](需求覆盖度清单.md)中的缺口给出**可直接进开发的默认规则**；全部数值为行业基准值，可调，但**结构不变**。
- **三个结构性决策需你确认**（其余按本方案默认执行即可）：① 资金链路走「担保交易」还是「不碰钱」；② 碎银↔人民币换算 1两=1元 是否接受；③ 孤儿功能（餐厅点餐/扫一扫/商户客服/优惠券）首版裁掉还是补需求。
- **合规底线已内嵌**：盲盒概率公示、账号注销、先发后审+机审、提现实名——这些不是可选项，是上架前提。

## 〇、补全思路

1. **惯例优先**：每个缺口先给「行业怎么做」（积分体系参考京东京豆/运营商积分，UGC 审核参考抖音/小红书，跑腿参考美团跑腿/UU，二手参考闲鱼）。
2. **数值可调、结构锁定**：奖励数值、比例均为基准值（标 📊），运营可后台调整；但「有上限、有频控、有流水」的结构是硬的。
3. **首版最小闭环**：孤儿功能默认首版裁掉，二期按数据决定是否补；宁缺毋滥，不让未定义的功能上首位。
4. **合规不谈判**：凡涉资金、概率公示、隐私、注销的条目，按监管要求执行，不提供「不做」选项。
5. 本文所有 ⚠ 与上篇[数据闭环推演](数据闭环推演.md)的 ⚠ 一一对应，PM 批注后以「已确认」版本替换本篇对应行。

## 一、碎银经济规则（闭合推演域二）

### 1.1 定价基准（先定基准，其余全部可推导）

> 行业惯例参考：京豆 100=1元（京东公开规则）、蚂蚁森林能量不换现金；运营商积分价值各不相同，需按目标运营商核实。碎银带「两」的货币意象，取 **1两碎银 = 1元人民币购买力** 为基准。（引用的外部产品规则在上线前逐条核实最新规则）

| 推导项 | 数值（📊 基准，后台可调） | 依据 |
| --- | --- | --- |
| 流量兑换率 | 10GB = 1两（§4 已定，与基准相容：流量成本≈1元/10GB 量级） | 需求文档已定 |
| 二手商品碎银支付 | 1两 = 1元 折算 | 定价基准 |
| 跑腿报酬碎银模式 | 1两 = 1元 折算（发布页按元填，可切碎银支付） | 消除评估 P1 #6 矛盾 |
| 打赏档位 | 1 / 5 / 10 / 50 两 四档 | 直播/内容平台惯例（小额固定档位） |
| 网费兑换 | 1两 = 1元 话费/网费 | 运营商积分惯例 |
| 盲盒 | 按奖品参考价 5~7 折定碎银价，概率公示（§1.4） | 盲盒规范指引 |

### 1.2 获取渠道规则（闭合「8 渠道无数值」）

| # | 渠道 | 奖励（📊） | 频控/上限 | 防刷 |
| --- | --- | --- | --- | --- |
| 1 | 流量兑换 | 10GB=1两，按月出账后**自动入账**（APP 内可查兑换记录） | 月度清零（未兑换流量） | 以计费系统数据为准，无法人工刷 |
| 2 | 看广告 | 0.5两/次 | 每日 5 次（§16.1 后台可配） | 完整观看回调发奖，SDK 防作弊 |
| 3 | 发帖 | 1两/帖 | 每日前 2 帖有效 | 机审通过才发奖；纯水帖（<10字/重复）不计 |
| 4 | 评论 | 0.5两/条 | 每日前 5 条有效 | 同上；同帖连评只计 1 条 |
| 5 | 点赞 | 0.1两/次 | 每日前 10 次有效 | 同一帖子对同一人只计 1 次 |
| 6 | 充值赠送 | 充值金额 5% 折两 | 无月上限（随消费自然增长） | 与真实支付回调绑定 |
| 7 | 邀请好友 | 被邀请人**完成学号认证**后发 5两，邀请人同得 5两 | 每人每月 10 人上限 | 设备指纹+手机号双去重；认证前不发奖（防小号） |
| 8 | 学长赠送 | 赠送方：**校园卡用户**专属权限 | 单次 ≤10两、每月 ≤2 次、接收方每月 ≤30两 | 不可逆转、走明细流水、超频冻结复核 |

**单日获取总上限：20两（📊）**（渠道 1 流量兑换除外，其有天然月度闸门）。超限部分顺延次日。

### 1.3 有效期与清零（闭合待定 #4 与 §15.2）

- **流量**：未兑换流量每月出账期（1-3日）后清零重计（§4 原规则，不动）。
- **碎银**：自**入账日起 60 天有效**（待定 #4 回答的规范化解读），滚动到期，先入先出扣减；到期前 7 天在「碎银明细」与消息中心提醒。
- **「本月到期碎银」（§15.2）**：= 未来 30 天内到期的碎银之和（按入账批次 FIFO 推导），规则确定后该待定项自动闭合。

### 1.4 盲盒合规（闭合评估 P1 #10）

- 抽奖页**公示全部奖品及中奖概率**（精确到 0.1%），保底规则：**累计 10 抽必出最高档奖品**。
- 概率与保底逻辑后台可配但**变更留审计日志**；用户端展示「本抽池概率快照」。

### 1.5 风控基线

- 渠道 3/4/5 发奖以**机审通过**为前提；账号被处置时未到期碎银冻结。
- 手动调整（16.5）仅限管理员角色，双人复核（>100两需二级审批），全程审计日志。
- 发行-消耗监控报表（§后台补全）周报给运营：周发行量、周消耗量、留存量、渠道占比。

## 二、资金链路方案（闭合推演域三，结构性决策 ①）

### 2.1 行业惯例参考

跑腿/二手平台的资金惯例只有两条路：**担保交易**（美团跑腿/UU：报酬先付到平台托管，完成后放款）或**不碰钱**（早期闲鱼：私下转账，平台只留证据）。涉资金归集必须有支付牌照或走持牌通道（微信支付「服务商分账/合单支付」、收付通类产品），否则构成二清。

### 2.2 推荐方案 A：担保交易（走持牌通道）

| 环节 | 规则 |
| --- | --- |
| 跑腿报酬 | 发布者支付 → 资金进微信/支付宝**分账托管**（平台不经手资金池）→ 发布者确认完成 → T+1 自动分账给接单者 |
| 过期退款 | 超时无人接单 → 原路自动退回，T+1 到账（闭合推演 🟠 缺口） |
| 平台抽成 | 首版 0%，后续如抽成走分账比例配置 |
| 充值（校园卡/网） | **不代收**：APP 内完成选档与下单，支付收单方为运营商/校方商户号（跳转或合单），APP 只做支付结果回执展示——规避代收对账与开票问题 |
| 自营商城 | 平台商户号收款，7 天无理由退货退款走原路 |
| 提现 | 仅跑腿报酬余额可提；满 10元、免手续费（首版）、T+1 到账；16.4 后台人工审核单笔 >500元 |

### 2.3 备选方案 B：不碰钱（合规负担最低）

- 平台不做任何代收：跑腿发布页引导**直接转账给接单者**（聊天页出示收款码），平台仅留存订单与聊天记录作纠纷证据；自营商城与充值跳转三方。
- 代价：纠纷没有仲裁依据（钱没过平台只能调解）、活动差价补款体验差、提现/收入余额模块整体下线。
- **适用**：若支付资质短期办不下来且想先上线验证需求。

### 2.4 二手交易（对应推演「二手未纳入订单体系」）

按闲鱼惯例**首版不做平台交易**：发布→聊天协商→线下面交/自行转账；平台提供举报与信用展示。二期视数据决定是否上担保交易。订单页「商品」Tab 仅指自营商城订单，二手不出订单（与推演 ⚠ 推测一致）。

## 三、账号体系方案（闭合推演域四，评估 P0 #4）

### 3.1 注册/登录

| 项 | 规则 |
| --- | --- |
| 注册方式 | 手机号 + 短信验证码（唯一注册通道） |
| 登录方式 | 短信验证码 / 密码（设计稿已有）/ **微信一键登录**（行业标配，绑定已有手机号后启用）/ 苹果设备 App Store 上架必须接 Apple 登录 |

### 3.2 用户三态判定（闭合「角色判定数据源未定义」）

| 角色 | 判定规则（权威数据源） | 解锁能力 |
| --- | --- | --- |
| 访客 | 注册但未通过认证 | 浏览/发布（先发后审）/原价购买 |
| 校园网用户 | 学号认证通过（16.5 人工审核）**或** 运营商用户清单匹配成功 | 三态展示、流量兑换碎银 |
| 校园卡用户 | 运营商套餐开通回执（需 A3 对接）或人工登记 | 活动碎银全抵、碎银赠送权限 |

- 判定缓存 24h，变更由后台事件触发刷新；多校区以「校区+学号」联合唯一（闭合推演 ⚠）。
- **降级路径**：若 A3 运营商对接不可得，校园卡用户暂由后台人工登记，接口到位后切换。

## 四、内容审核方案（闭合推演域六，评估 P0 #5）

### 4.1 审核模式（参考主流内容平台做法：机审+人审复核组合）

| 项 | 规则 |
| --- | --- |
| 模式 | **先发后审（机审秒级）+ 高危人审**：机审通过即公开，命中疑似的进入「仅自己可见」待人工队列 |
| 机审 | 采购三方（数美/易盾/网易盾，文本+图片+视频），覆盖帖子/评论/昵称/头图/涂鸦留言 |
| 敏感词 | 平台自有词库 + 三方词库双跑；词库后台可维护 |
| 人审 SLA | 疑似队列 2 小时内处置（工作时间）；夜间积压转次日 9 点 |
| 举报 | 举报入口全场景统一（帖子/评论/用户/跑腿任务）；举报**不影响**内容可见性，进 16.4 投诉队列按 SLA 处置；处置结果以系统通知回执举报人（闭合推演 9.2 #5） |

### 4.2 违规处置阶梯（行业惯例：分级处罚）

| 次数 | 处置 |
| --- | --- |
| 第 1 次 | 内容下架 + 站内警告 |
| 第 2 次 | 禁言 1 天 |
| 第 3 次 | 禁言 7 天 |
| 第 4 次及以上 | 封号（16.5 已有封禁位）；涉违法内容直接封号并留存记录 |

- 发布者被处置时其待发碎银奖励冻结（与 §1.5 衔接）；申诉入口在「我的投诉」，7 日内人工复核。

### 5.2 跑腿模式二选一（闭合评估 P1 #6/#7/#8，按美团跑腿惯例）

- **接单模式定为「抢单」**（先到先得），删除「多人申请→手动确认」；理由：校园场景任务报酬低、时效强，抢单链路短。
- 报酬模式定为「人民币为主、碎银可抵扣」：发布页按元定价，可勾选用碎银抵扣（1两=1元）；删除 5.5「仅人民币」与 11.4「双模式」的矛盾表述。
- 状态机补全为评估文档 §五 的七态（含已取货/已送达），「已过期」为终态且触发自动退款。
