# 开发区域划分

## 结论（给 PM）

- **判断**：功能点共 12 个业务模块 + 8 个后台模块 + 1 个平台层，全部可归入 5 个开发区域（App-1、App-2、后端 A、后端 B、后端 C）+ 2 个按固定节点接入的角色（前端、UI），无功能点无归属。
- 分工与《端与交付物清单》『分工方案』一致：App 双人分包（跨端一套代码）、后台页面由后端 B 接管、三方对接归后端 C。
- **需要你确认**：无新增待确认项，本文为执行层划分，直接按表开工。

## 开发区域说明

| 开发区域 | 覆盖范围 | 说明 |
| --- | --- | --- |
| App-1 | 用户端核心闭环包（跨端框架，双平台一套代码） | 账号、首页、碎银、订单、消息、我的 |
| App-2 | 用户端内容与交易包（同上） | 发布、校友圈、跑腿、花名册、校园网办理、二手 |
| 后端 A | 核心业务域服务端 | 碎银账本、订单、跑腿状态机 |
| 后端 B | 平台域服务端 + 后台管理页面（Vue + Element） | 账号体系、内容管理、审核、用户管理、全部后台页面 |
| 后端 C（兼架构） | 资金链路 + 三方接入 + 部署运维 | 支付/分账/对账、运营商、机审、IM、选型 |
| 前端（按节点接入） | 复杂后台交互页 | 不常驻，S3 冲刺内进场约 2 周（审核工作台等），接入时间见[排期与里程碑计划『前端与 UI 接入安排』](../PM/排期与里程碑计划-给PM.md) |
| UI（按节点接入） | 设计稿切图标注、新增页视觉、走查 | 不驻场；M0 完成一期 8 包切图标注，收尾阶段走查约 1 周（节点同上） |

## 后台模块 → 功能点 → 开发区域

后台页面统一由后端 B 实现（Vue + Element，初稿借助辅助工具生成）；审核工作台等复杂交互页由前端在 S3 冲刺内进场完成。

| 后台模块 | 功能点 | 开发区域 | 期 |
| --- | --- | --- | --- |
| 内容配置 | Banner/广告位、商城商品/分类/限时特惠、校园通知、跑腿协议 | 后端 B | ★ |
| 用户管理 | 用户列表/封禁、学号认证审核、碎银手动调整（双人复核） | 后端 B | ★ |
| 审核工作台 | 机审结果流、人审批量处置、敏感词库、违规阶梯执行 | 后端 B + 后端 C（机审对接） | ★ |
| 跑腿管理 | 任务监控/异常处理、投诉处理、提现审核 | 后端 B | ★ |
| 权限审计 | RBAC 三角色、敏感操作审计日志 | 后端 B | ★ |
| 财务对账 | 日账单比对、退款管理、异常账务工单 | 后端 C（账务）+ 后端 B（页面） | ★基础，☆完善 |
| 风控 | 碎银经济数值配置、黑名单、冻结/解冻 | 后端 B | ☆ |
| 数据报表 | 碎银发行-消耗周报、DAU/留存、核心漏斗 | 后端 C（埋点/统计）+ 后端 B（页面） | ☆ |
| 套餐管理/配置中心 | 套餐档位、FAQ、系统参数 | 后端 B | ★ |
